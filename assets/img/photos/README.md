# Shop photos — drop-in folder

Every photo slot on the site loads its image from this folder. Until a file
exists, the slot shows a labelled placeholder; the moment you add the file
with the exact name below, the photo appears — **no code changes needed**.

Use JPG (or PNG). Landscape shots work best. Aim for ~1600px on the long edge.
