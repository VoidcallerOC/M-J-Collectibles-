# Logo

The boot screen shows an **arcade recreation** of the M&J logo (built in CSS).

To use the **real logo image** instead, add a file here named exactly:

```
assets/img/logo.png
```

(PNG with a transparent background works best; SVG also fine if you rename the
reference in `index.html`.) As soon as that file exists, the site automatically
shows it in place of the recreation — no code changes needed. Remove the file to
fall back to the recreation.

Product/shop photos live in `assets/img/photos/` — see the README there.
